AI Virtual Formation 🎓🤖

AI Virtual Formation is a modern web-based e-learning platform built with ASP.NET Core MVC (C#) and MySQL. The project integrates Anam.ai's AI Avatar SDK to provide an interactive virtual instructor capable of communicating with learners in real time.

The objective of this project is to enhance online education by combining artificial intelligence, virtual avatars, and modern web technologies to create an engaging and personalized learning experience.

Features
🔐 User authentication with JWT
👨‍🏫 AI Virtual Trainer powered by Anam.ai
🎤 Real-time voice interaction with the AI avatar
📚 Training module management
👥 User and trainer management
🗂 Course organization
🔒 Secure REST API
💻 Responsive and modern user interface
🎥 Live AI avatar streaming
🌐 Integration with ASP.NET Core MVC
